START WITH WHAT YOU ALREADY HAVE

A WebP reference.
An SVG character.

The reference tells you how it moves.
The SVG tells you what it is made of.

01 / OBSERVE

Extract the motion.

Prepare a scrubber sheet, original frame timing and an inventory of SVG part IDs.

pup prepare reference.webp artwork.svg work/
02 / AUTHOR

Keep the curves simple.

With an agent or by hand, map parts to a rig and editable keyframes. Preparation alone does not infer a finished animation.

Use the reconstruction prompt ↗
03 / PACK

Ship one puppet.

Compile the authored SVG and motion into PUP. Load it in Canvas or render it as native SVG.

pup import rig.svg motion.json animation.pup
IN YOUR APP

Named actions.
A small API.

import { CanvasPlayer } from '@henrywhuang/pup';

const actor = await CanvasPlayer.load(canvas, 'fox.pup');
actor.play('correct');
actor.play('wrong');
actor.dispose();
